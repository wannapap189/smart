# SmartGift Thailand

เว็บไซต์สินค้าพรีเมียมและชุดของขวัญองค์กรของ SmartGift Thailand ประกอบด้วยข้อมูลหน้าสินค้า แคตตาล็อก บทความ และช่องทางขอใบเสนอราคา

## ทะเบียนสินค้าสำหรับฐานข้อมูล

ทะเบียน Excel สำหรับทีมมี 14 ไฟล์ ครบทั้ง 3,913 รุ่นที่แสดงบนเว็บไซต์ ณ วันที่ 19 พฤศจิกายน 2569 แบ่งเป็นสินค้าพรีเมียม 2,793 รุ่น และชุดของขวัญองค์กร 1,120 รุ่น ตรวจแล้วว่ารหัสสินค้าและลิงก์หน้าสินค้าตรงกับเว็บทุกรุ่น และไม่มีรหัสซ้ำข้ามไฟล์

ให้นำเข้าชีต **ทะเบียนสินค้า** ของแต่ละไฟล์ โดย 1 แถวคือสินค้า 1 รุ่น ใช้คอลัมน์ **รหัสสินค้า** (คอลัมน์ A) เป็น `sku` ในฐานข้อมูล เก็บเป็นข้อความและกำหนดให้ค่าไม่ซ้ำ เพื่อรักษาตัวอักษร ขีดกลาง และเลขศูนย์ตามรหัสเดิม สำหรับชุดของขวัญให้ใช้รหัสโรงงานเดิมทุกตัว เช่น `TDD03-2` และ `TYD0038`

เมื่อนำเข้าครั้งถัดไป ให้ปรับปรุงสินค้าที่มี `sku` เดิม และเพิ่มรายการเมื่อพบรหัสใหม่ คอลัมน์ **หน้าเว็บสินค้า** (คอลัมน์ F) ใช้เปิดตรวจรุ่นนั้นบนเว็บได้ ทีมรับไฟล์ Excel จาก ZIP ภายในของ SmartGift เนื่องจากทะเบียนมีช่องต้นทุนสำหรับงานหลังบ้าน

## เปิดเว็บไซต์บนเครื่อง

ติดตั้ง Python 3.11 ขึ้นไปและ Node.js 24 จากนั้นรันคำสั่งในโฟลเดอร์หลักของ repository

```shell
python restore-media.py
cd smartgift-site
node serve.mjs
```

เปิด [หน้าแรก](http://127.0.0.1:4173/smartgift/) เพื่อดูเว็บ โปรแกรมโหลดภาพ วิดีโอ และ PDF จาก [GitHub Release](https://github.com/wannapap189/smart/releases/tag/web-2026-11-19) และตรวจ SHA-256 ก่อนนำมาใช้ สามารถดาวน์โหลดแพ็กจากหน้า Release เอง แล้วใช้ `python restore-media.py --archives PATH` โดยแทน PATH ด้วยโฟลเดอร์ที่เก็บแพ็กทั้งหมด

## แก้และตรวจเว็บ

แก้ไฟล์ใน `smartgift-site/src` แล้วรันคำสั่งต่อไปนี้จากโฟลเดอร์ `smartgift-site` หลังติดตั้งสื่อแล้ว

```shell
node src/build.mjs
node src/verify.mjs
```

[llms.txt](llms.txt) รวบรวมลิงก์หลักสำหรับค้นข้อมูล SmartGift ส่วน [รายการสื่อและค่า SHA-256](media-manifest.json) ใช้ตรวจฉบับของไฟล์ดาวน์โหลด
